# 계약서 검토 · 내용증명 앱 (contract-app)

계약서를 넣으면 **위험해 보이는 조항을 조항별로 표시**하고, 관련 **법령 원문(법제처)** 과 **수정안 문구**를 보여 줍니다.
이어서 **내용증명 초안**을 양식대로 만들고 **발송 전 점검**까지 해 줍니다. 내 PC 에서만 돌아가는 로컬 앱입니다.

| 화면 | 하는 일 |
|---|---|
| ① 계약서 검토 | .docx · .txt 파일 또는 붙여넣기 → 조항별 위험도(높음·중간·낮음), 이유, 확인할 점, 관련 법령 원문, 수정안. 빠진 조항(기간·대금·해제·손해배상·분쟁해결) 알림. 보고서 Word·텍스트 저장 |
| ② 내용증명 작성 | 대금 청구 · 이행 최고 및 해제 · 하자 보수 · 보증금 반환 · 해지 · 손해배상 양식. 미리보기, 발송 전 점검(빈칸·기한·협박성 표현·주민번호), 인쇄 · Word 저장 |
| ③ 법령 · 판례 찾기 | 법령 조문 원문, 판례 검색과 판결요지 |

- **계약서 본문은 PC 밖으로 나가지 않습니다.** 법제처에는 법령명·조문번호·판례 검색어만 보냅니다.
- 외부 패키지가 없습니다. Node.js 만 있으면 됩니다.

> **이 앱은 법률 자문이 아닙니다.** 규칙에 따라 검토할 자리를 표시할 뿐이며, 표시되지 않은 조항도 문제가 될 수 있습니다.
> 중요한 계약이나 다툼은 변호사 등 전문가의 검토를 받으세요.

## 설치

### 1. 준비물

| 무엇 | 확인 | 없으면 |
|---|---|---|
| Node.js 18 이상 | `node -v` | https://nodejs.org 에서 LTS 설치 |
| 법제처 OC (인증키) | — | https://open.law.go.kr 회원가입 → OPEN API 신청 (승인 1~2일) |

**법제처 OC 는 각자 본인 것으로 신청합니다.** OC 는 가입 이메일의 아이디 부분입니다(`hong@gmail.com` → `hong`).
신청할 때 **사용할 PC 의 공인 IP** 를 등록하고, 조회 항목에서 **법령(본문)** 과 **판례** 를 꼭 체크하세요.

### 2. 받기
- **카카오톡으로 zip 을 받았다면**: PC 에 저장하고 원하는 폴더에 압축을 풉니다.
- **GitHub 에서**: 초록색 **Code → Download ZIP** 으로 받아 압축을 풉니다.

### 3. 실행

**Windows** — `실행.bat` 을 더블클릭합니다.
1. 처음 실행하면 `.env` 파일을 만들고 메모장을 엽니다. `LAW_OC=본인OC` 의 `본인OC` 를 내 OC 로 바꾸고 저장합니다.
2. `실행.bat` 을 다시 더블클릭하면 `npm install` 을 한 번 실행하고 브라우저가 열립니다.

**직접 하려면 (Windows · macOS 공통)**
```bash
npm install
npm start
```
macOS 는 `sh start.sh` 로도 실행됩니다. 브라우저에서 **http://localhost:5188** 을 엽니다.
오른쪽 위에 **"법제처 연결됨"** 이 초록색으로 뜨면 준비된 것입니다. 끄려면 실행 창을 닫습니다.

## Claude 로 더 정밀하게 검토하기 (선택)

Claude Code 를 쓰고 있다면 함께 들어 있는 **`claude-skill/계약검토`** 폴더를 스킬로 설치하세요.
AI 가 조항을 직접 읽고, 이 앱을 통해 법령 원문을 확인한 검토 보고서와 내용증명 초안을 만듭니다(API 키 불필요).

1. `claude-skill/계약검토` 폴더를 통째로 복사해 아래 위치에 붙여넣습니다.
   - Windows: `C:\Users\<사용자>\.claude\skills\계약검토`
   - macOS: `~/.claude/skills/계약검토`
2. 이 앱을 켜 둔 상태에서 Claude Code 에 `계약서 검토해줘` 라고 하며 계약서를 첨부합니다.

## 문제가 생기면

| 증상 | 원인 · 조치 |
|---|---|
| 실행 창에 `[설정 오류] ... LAW_OC` | `.env` 에 OC 를 안 적었습니다 |
| 상단 "법제처 연결 안 됨" (마우스를 올리면 이유) | **인증 실패**: OC 미승인 또는 open.law.go.kr 에 등록한 IP 가 지금 PC 와 다름 |
| 법령 칩을 눌러도 원문이 안 나옴 | 신청할 때 "법령" 조회 항목을 체크했는지 확인 |
| 판례 검색 결과 0건 | "판례" 조회 항목 신청 여부 확인. 더 짧은 키워드로 검색 |
| hwp · PDF 를 넣을 수 없음 | 한글·PDF 에서 본문을 복사해 붙여넣으세요 |

## 지켜 주세요
- **`.env` 는 공유하지 마세요.** 본인 OC 가 들어 있습니다(GitHub 에는 `.gitignore` 로 올라가지 않습니다).
- 이 앱은 본인 PC 에서만 열립니다(`127.0.0.1`). 인터넷에 공개하는 서버로 쓰지 마세요.
- 내용증명은 "이런 내용을 이날 보냈다"는 증명일 뿐 강제력은 없습니다. 금전 청구의 시효를 멈추려면
  내용증명(최고) 후 **6개월 안에** 지급명령·소송 등을 해야 합니다(민법 제174조).
- 위험 조항 규칙과 내용증명 양식은 `public/rules.js` 에 있습니다. 고쳐 쓸 수 있습니다.
